# Ancient astronomical clock asset

`astronomical-clock.glb` is original geometry authored for this page with Blender 4.3.2 by `../../tools/build-clock.py`. It contains a walnut housing, brass ornament, acanthus relief, armillary globes, dial, and separately pivoted `MinuteHand` / `HourHand` nodes. Static parts are joined by material. No third-party model was downloaded or purchased.

Walnut grain and bronze patina maps are generated by the build script. `../textures/astronomical-dial.png` is generated artwork created with the image-generation tool on 2026-10-10 for this project. The prompt requested an orthographic navy-enamel dial with gold zodiac engravings, celestial charts and Roman numerals, without hands, housing or a room. Its original output remains at `/workspace/generated_images/exec-04421365-9237-40e1-9914-b425eef2d418.png`. The dial is decorative artwork, not a scientifically accurate astronomical instrument. It is embedded in the GLB, along with the two authored surface maps.

The user's supplied library image guides the composition, materials and mood. It is not used as a background, copied into the model, or claimed as our browser render.

Rebuild from the repository root:

```sh
blender -b --python mainpage_version/ACTIVE/tools/build-clock.py -- /absolute/path/to/astronomical-clock.glb
```

The generated dial PNG must remain at its checked-in path when rebuilding. Model generation requires Blender and its bundled NumPy; opening the web page requires neither. No external textures, credentials, paid assets, or model-service accounts are required at runtime.
